**SMK Negeri 1 Gunung Sindur - Jawa Barat**

Platform AI Generator Modul Ajar Kurikulum Merdeka berbasis **Pembelajaran Mendalam (Deep Learning)**, **GBLHS (Gerakan Peduli dan Berbudaya Lingkungan Hidup di Sekolah / Adiwiyata)**, serta kearifan lokal **Gapura Panca Waluya Jawa Barat**.

## 🌟 Fitur Unggulan
1. **Progressive Web App (PWA):** Dapat di-install langsung di Laptop/PC (Windows, Mac, Linux) tanpa perlu mengunduh installer eksternal.
2. **Karakteristik Prinsip Dasar 3 Indikator Utama Deep Learning:**
   - **Berkesadaran:** Murid terlibat secara penuh, sadar, dan aktif dalam proses berpikir.
   - **Bermakna:** Pengetahuan dikaitkan langsung dengan konteks nyata & kehidupan sehari-hari.
   - **Menggembirakan:** Suasana belajar diciptakan secara positif, interaktif, dan menyenangkan tanpa tekanan.
3. **8 Dimensi Profil Lulusan Pembelajaran Mendalam.**
4. **Integrasi GBLHS & Budaya Kerja Vokasi Hijau.**
5. **Format Resmi Presisi Cetak A4 / PDF dengan Kop Surat SMK Negeri 1 Gunung Sindur.**

## 💻 Cara Install Aplikasi di Laptop/PC (Windows / Mac)

Setelah aplikasi di-deploy dan dibuka dari URL GitHub Pages HTTPS Anda:

### Opsi A (Melalui Tombol UI Aplikasi):
1. Buka tautan HTTPS GitHub Pages di Google Chrome, Microsoft Edge, atau Brave pada Laptop.
2. Klik tombol hijau **"Install di Laptop"** yang berada di navigasi bagian atas.
3. Klik **Install** pada pop-up konfirmasi browser.

### Opsi B (Melalui Chrome/Edge Bar):
1. Buka URL aplikasi di browser.
2. Klik ikon install PWA 💻 di sebelah kanan address bar browser (atau titik tiga `...` -> *Save and Share* -> *Install Page as App*).
3. Aplikasi akan otomatis terpasang di Desktop & Start Menu Laptop Anda dengan tampilan aplikasi mandiri!
