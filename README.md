🛠️ Langkah Upload & Deploy di GitHub Pages (100% Gratis)
Langkah 1: Buat Repositori GitHub Baru
Masuk ke akun GitHub.
Klik tombol New (atau tanda + di pojok kanan atas) untuk membuat repositori baru.
Beri nama repositori, contoh: modul-ajar-smkn1gs.
Pilih opsi Public.
Klik Create repository.
Langkah 2: Unggah File Aplikasi
Di halaman repositori baru Anda, klik tombol uploading an existing file.
Unggah file index.html yang ada di folder ini.
Klik tombol hijau Commit changes.
Langkah 3: Aktifkan GitHub Pages
Masuk ke menu Settings pada repositori GitHub Anda.
Pada navigasi sebelah kiri, klik Pages.
Pada opsi Build and deployment -> Branch:
Ubah None menjadi main (atau master).
Folder biarkan tetap / (root).
Klik tombol Save.
Tunggu 1-2 menit. GitHub Pages akan memunculkan URL resmi HTTPS Anda (contoh: https://username-anda.github.io/modul-ajar-smkn1gs/).

💻 Cara Install Aplikasi di Laptop/PC (Windows / Mac)
Setelah aplikasi di-deploy dan dibuka dari URL GitHub Pages HTTPS Anda:
Opsi A (Melalui Tombol UI Aplikasi):
Buka tautan HTTPS GitHub Pages di Google Chrome, Microsoft Edge, atau Brave pada Laptop.
Klik tombol hijau "Install di Laptop" yang berada di navigasi bagian atas.
Klik Install pada pop-up konfirmasi browser.
Opsi B (Melalui Chrome/Edge Bar):
Buka URL aplikasi di browser.

Klik ikon install PWA 💻 di sebelah kanan address bar browser (atau titik tiga ... -> Save and Share -> Install Page as App).

Aplikasi akan otomatis terpasang di Desktop & Start Menu Laptop Anda dengan tampilan aplikasi mandiri!
