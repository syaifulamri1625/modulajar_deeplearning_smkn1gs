Panduan Upload ke GitHub & Install di Laptop

Cara Install Aplikasi di Laptop/PC:
  1. Buka aplikasi ini yang sudah di-deploy di GitHub Pages menggunakan Google Chrome, Microsoft Edge, atau Brave di Laptop.
  2. Klik tombol hijau Install di Laptop di pojok kanan atas navbar.
  3. Atau klik ikon install PWA yang muncul di bilah alamat (*address bar*) browser Anda.
  4. Aplikasi akan terpasang sebagai aplikasi desktop mandiri (*Progressive Web App*) tanpa memerlukan instalasi software tambahan!

Langkah Upload ke GitHub Pages (Gratis):

  1. Buat repositori baru di GitHub (misal: modul-ajar-smkn1gs) dan atur ke **Public**.
  2. Simpan kode aplikasi ini sebagai file bernama index.html.
  3. Unggah (*Upload*) file index.html tersebut ke dalam repositori GitHub Anda.
  4. Buka menu **Settings** -> **Pages** pada repositori GitHub tersebut.
  5. Pada bagian **Build and deployment -> Branch**, pilih main (atau master) dan folder / (root), lalu klik **Save**.
  6. Tunggu 1-2 menit. Tautan HTTPS aktif Anda akan muncul (contoh: https://username.github.io/modul-ajar-smkn1gs/).
